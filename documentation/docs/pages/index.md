# ACCESS-CM3 Evaluation Figures

Diagnostic figures from ACCESS-CM3 experiments, generated by the
[access-cm3-paper-1](https://github.com/ACCESS-Community-Hub/access-cm3-paper-1/)
analysis notebooks. See navigation on the left to browse diagnostics as
delineated by notebook. The website is intended to help users discover
and compare diagnostics. All discussion of the diagnostics occurs on
GitHub issues (see links in Figure captions).

Boschat, Ghyslaine; Boucher, Romain; Bull, Christopher Yit Sen; Chun,
